# Changelog

## [1.0.0] - 2026-08-25

First release.

### Added

- A HINT row in the Pokedex side menu, spliced in after AREA, showing the map,
  method, level band, rarity and gate for whichever species the cursor is on.
  The text comes from Gen151's own resolved placement rows through
  `mod.find("gen151").exports`, so it cannot disagree with the spawn.
